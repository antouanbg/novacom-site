## Текущо състояние
- GitHub: https://github.com/antouanbg/novacom-site (публично), с включен GitHub Pages, cname `novacom.bg`.

- Деплой: GitHub Actions (`.github/workflows/deploy.yml`) при push в `main` → GitHub Pages.
- Локален преглед: `npm run build`, след това сървър за папката `out/`.
- DNS (панел SuperHosting/bgdns, NS redirns1/2, както при gridex.tech): `@` A → 185.199.108.153 / .109 / .110 / .111 (и четирите са добавени), `www` CNAME → antouanbg.github.io, MX Google (5 записа) и TXT google-site-verification запазени. **Основен адрес: `novacom.bg`**, `www` препраща към него (GitHub Pages cname = novacom.bg).
- **Сайтът е на живо: https://novacom.bg** (2026-09-24). Let's Encrypt сертификат за `novacom.bg`, HTTPS задължителен (http → https). `http://www` препраща към `https://novacom.bg`. **Отворено (към 2026-09-24 23:30):** `https://www.novacom.bg` още дава грешка в сертификата. Направено: домейнът беше премахнат и добавен отново, после основният адрес беше сменен на `www` и върнат на `novacom.bg`; GitHub заяви нов сертификат за двата домейна (`domains: [novacom.bg, www.novacom.bg]`), но състоянието му стои `new` вече над час. **Временно `https_enforced=false`** (не може да се включи, докато сертификатът не е `approved`), затова `http://novacom.bg` не препраща към https. Фонов процес проверява на 5 мин и щом стане `approved`, включва задължителния HTTPS. Ако до 24 ч няма промяна: пак `DELETE`/`PUT` на домейна в Pages или тикет към GitHub Support. Проверка: `gh api repos/antouanbg/novacom-site/pages --jq .https_certificate`.
- Google Search Console: клиентът да подаде `https://novacom.bg/sitemap.xml` (домейнът е потвърден с TXT записа).
- `gh` CLI: `~/bin/gh` (Intel Mac, macOS 26), логнат като `antouanbg`.

## Структура на страниците (по модела на sonnis-energy.com)
**Начало**
1. Hero + CTA „Поискай оферта“
2. 3 предимства: Вашите нужди на първо място · Цялостно решение „до ключ“ · Устойчивост
3. Бързи входове: За бизнеса (C&I) · Енергийни общности · Домакинства
4. Нашите услуги: Консултация и анализ · Изграждане · Поддръжка
5. Нашите продукти: панели · инвертори · BESS · конструкции · EMS → „Научете повече“
6. Избрани проекти → „Всички проекти“
7. CTA + footer (Услуги · За нас · Полезна информация · Социални мрежи)

**Решения → всяка подстраница** (Индустрия, Търговски, Земеделие, Енергийни общности, Домакинства)
1. Заглавие на решението
2. Цялостни решения: от концепция до реализация
3. Експертна консултация и управление на проекта
4. Предимства: Икономичност · Независимост · Устойчивост
5. CTA оферта

**Продукти** (добавено спрямо Sonnis): категория → карти на продукти (марка, модел, ключови параметри, PDF datasheet) → CTA оферта

**Услуги → подстраници:** описание, етапи, CTA

**Проекти:** мрежа от карти „Система за [тип клиент] [X] kWp / [Y] kWh“ + снимка + филтър (C&I / частни / общности) → карта „Къде можете да ни намерите“

**За нас**
- Кои сме ние: история (30+ години ИТК) · Партньорства и членства · Нашата отговорност · снимки на млади хора на работа
- Нашата визия: Устойчива енергия · Защо ФЕЦ си заслужава · Ръководство

**Контакт:** Офис · Контакти · форма „Вашето съобщение“ · карта

## Как е устроен кодът
- `src/content/site.ts`: всички текстове BG/EN, менюта, решения, продукти, услуги, ID-та на снимките
- `src/app/[lang]/…`: страниците; `src/app/(root)/page.tsx`: пренасочване `/` → `/bg/` или `/en/`

- Текстовете на решенията и продуктите са общи описания от Claude. **Клиентът трябва да ги прегледа.**
